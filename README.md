# Vegas Sports & Hockey case study (Commerce Pundit)

Case study page for Vegas Sports & Hockey (uniformsport.com), designed to match the CMES case study on commercepundit.com.

## Structure
| Folder | Purpose |
|---|---|
| `prototype/` | Standalone HTML prototype. Open `prototype/index.html` in a browser. |
| `wordpress/` | WordPress theme template and assets. Install steps are in [wordpress/README.md](wordpress/README.md). |
| `Images/` | Source images for the page (sizes listed below). |
| `Client/` | Original client HTML, used as the content source. |

## Deploy to WordPress
1. Copy `wordpress/single-pf-vegas-sports-hockey-case-study.php` and `wordpress/vegas-case-study/` into the active theme root.
2. Set the entry template to **Vegas Sports & Hockey Case Study**.
3. Check on staging with the real header and footer before publishing.
